Install

Up and running in three steps

  1. Install

    Open the downloaded .dmg and drag Reqly into your Applications folder.

  2. Open

    Launch Reqly from Applications or Spotlight. The first launch takes a few seconds while it sets up its local database.

  3. Create your account

    Pick a name, email and password. The account lives only on your Mac and keeps your workspace private.

macOS says Reqly is from an unidentified developer? Right-click Reqly in Applications, choose Open, then confirm. You only need to do this once.
For developers

Run from source

Reqly is a Spring Boot application. With Java 17 or newer installed, clone the repository and start it with Gradle, then open http://localhost:8899 in your browser.

$ git clone https://github.com/ShaikRaihan93/reqly.git
$ cd reqly
$ ./gradlew bootRun
